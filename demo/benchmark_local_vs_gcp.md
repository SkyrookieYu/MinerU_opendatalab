## 結論

1. **GCP (CPU) 比 Local (GPU) 慢約 5.8 倍**
2. 網路延遲影響提交時間（0.01s → 0.20s），但對整體影響小
3. 主要瓶頸在於 **GPU vs CPU 的處理能力差異**

---

## 建議

如需提升 GCP 效能，可考慮：

1. **使用 GPU VM 實例**
   - NVIDIA T4: 較經濟
   - NVIDIA V100/A100: 更高效能

2. **優化配置**
   - 增加 CPU 核心數
   - 增加記憶體

3. **批次處理**
   - 對於大量文件，可考慮使用 Batch API
